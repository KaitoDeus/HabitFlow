## Danh sách tài liệu:

1.  **[today_tab.md](today_tab.md):** Tài liệu màn hình Hôm nay (Progress, Confetti, Adaptive UI).
2.  **[habit_tab.md](habit_tab.md):** Quản lý thói quen (Thêm, Xóa, Lưu trữ).
3.  **[goals_tab.md](goals_tab.md):** Thiết lập và theo dõi mục tiêu dài hạn.
4.  **[stats_tab.md](stats_tab.md):** Thống kê lịch, biểu đồ và các chỉ số hiệu suất.
5.  **[settings_tab.md](settings_tab.md):** Cài đặt chủ đề, sao lưu JSON và lời chào tùy chỉnh.
6.  **[data_storage.md](data_storage.md):** Cấu trúc Room DB, DataStore, Gamification logic và Home Screen Widget.
